# Cat Suika — Telegram Mini App 🐱🍉

Полноценная игра-головоломка по мотивам **Suika Game**, в которой вместо фруктов падают очаровательные котята. Две кошки одного уровня объединяются в одну кошку следующего уровня, пока не появится легендарный **Король Котов**!

---

## 📸 Скриншоты и Визуальный Стиль

Дизайн игры полностью воссоздаёт уютную атмосферу Suika Game:
* ☁️ **Облачко-дроппер** с направляющей линией падения котика
* 🫧 **Глянцевые пузырьки** «Score», «Best Score» и «Next»
* 🔄 **Circle of Evolution** — кольцо 11 уровней эволюции кошек
* 🏆 **Daily Ranking** — таблица лидеров с призовыми лентами
* 🐾 **Милые мордочки** котиков с анимацией моргания, шевеления ушками и физической деформацией при столкновении

## 🪙 Точные правила начисления монет

1. **Базовое объединение кошек:**
   * Уровень 1 ➔ 2: **+1 монета**
   * Уровень 2 ➔ 3: **+2 монеты**
   * Уровень 3 ➔ 4: **+4 монеты**
   * Уровень 4 ➔ 5: **+8 монет**
   * Уровень 5 ➔ 6: **+12 монет**
   * Уровень 6 ➔ 7: **+18 монет**
   * Уровень 7 ➔ 8: **+25 монет**
   * Уровень 8 ➔ 9: **+35 монет**
   * Уровень 9 ➔ 10: **+50 монет**
   * Уровень 10 ➔ 11 (*Король Котов*): **+150 монет!**

2. **Комбо-бонусы (быстрые слияния в течение 1.8 сек):**
   * x2 Combo: **+2 бонусные монеты**
   * x3 Combo: **+5 бонусных монет**
   * x4 Combo: **+10 бонусных монет**
   * x5+ Combo: **+20 бонусных монет**

3. **Завершение партии:**
   * **Бонус за счёт:** 1 монета за каждые 100 набранных очков.
   * **Новый рекорд:** **+50 бонусных монет** при побитии своего рекорда!

4. **Ежедневный бонус (Серия 7 дней):**
   * День 1: 50 монет
   * День 2: 100 монет
   * День 3: 150 монет
   * День 4: 250 монет
   * День 5: 400 монет
   * День 6: 600 монет
   * День 7: 1000 монет 👑

5. **Ежедневные задания:**
   * *«Мяу-старт»* (объединить 15 кошек): **60 монет**
   * *«Цепная лапка»* (сделать комбо x3): **100 монет**
   * *«Мастер уюта»* (набрать 1500 очков): **150 монет**

## 🤖 Бот Telegram: Команды и Текст /start

### Команды бота:
* `/start` — Запустить Cat Suika и открыть главное меню
* `/play` — Быстрый запуск Mini App
* `/help` — Правила игры и обучение
* `/top` — Таблица лучших рекордов

### Текст приветствия при `/start`:
```text
🐱 Добро пожаловать в Cat Suika! 🍉

Сбрасывай милых котиков в коробку, объединяй одинаковых и вырасти легендарного Короля Котов!

✨ В игре тебя ждёт:
• Залипательная физика и милые мурлыкающие котики
• 11 уровней эволюции пород
• Коллекции и уютные темы оформления
• Ежедневные награды и задания с монетами
• Соревнования за лучший счёт в таблице лидеров

Нажми кнопку «Играть в Cat Suika» ниже, чтобы запустить игру! 👇
```
*Кнопки инлайн-клавиатуры:*
* `[ 🎮 Играть в Cat Suika ]` (открывает WebApp)
* `[ 🏆 Таблица лидеров ]`
* `[ 📖 Как играть ]`

## 🛠️ Стек технологий

* **Frontend:** TypeScript, Vite, Matter.js (2D физика), HTML5 Canvas, Web Audio API, Canvas Confetti.
* **Telegram Integration:** Telegram WebApp JS SDK (`ready()`, `expand()`, `requestFullscreen()`, `HapticFeedback`, `CloudStorage`).
* **Backend:** Node.js, Express, встроенный Telegram Bot Poller, валидация `initData` через HMAC-SHA256, база данных JSON.
* **Деплой:** Render Web Service, GitHub.

## 🚀 Запуск и Разработка

```bash
# 1. Установка зависимостей
npm install

# 2. Сборка проекта
npm run build

# 3. Запуск сервера
npm start
```
Сервер будет доступен по адресу `http://localhost:3000`.
